# Sanctum Social Initiative

Social initiative for **Cyberpunk RED** on **Foundry VTT**.

A social encounter is a normal combat encounter with one flag. Initiative is CPR's normal initiative with four changes:

1. Uses **COOL** instead of REF.
2. **Speedware** adds nothing.
3. **Solo Initiative Reaction** adds nothing.
4. **Charismatic Impact** rank is added (plus any Active Effect on `bonuses.charismaticImpact`).

Everything else stays normal CPR initiative.

## Install

Download the repo as a zip, unzip it into `Data/modules/sanctum-social-initiative/`, then enable the module in Manage Modules.

## Usage

1. Create an encounter and add tokens as normal.
2. As GM, click the speech-bubble button in the combat tracker header to mark it social (highlighted when on). Click again to switch back.
3. Roll initiative as normal.

If you switch after rolling, reset and re-roll.
